# 💻 Object-Oriented Programming — C#

A C# console application developed as part of my Computer Science studies at the University of Sunderland to practise object-oriented programming concepts.

## 🌸 Overview

This project was created while developing my understanding of programming with C# and object-oriented programming.

The project uses a console-based application to practise structuring a program using classes, objects and methods.

## 🛠️ Technologies

- C#
- .NET
- Visual Studio
- Git/GitHub

## 🧠 Concepts Practised

- Classes and objects
- Methods
- Variables and data types
- Object-oriented programming principles
- Console input and output
- Program structure

## ▶️ Running the Project

### Requirements

- Visual Studio
- .NET SDK compatible with the project

### Steps

1. Clone or download this repository.
2. Open `ConsoleApp1.slnx` in Visual Studio.
3. Build the solution.
4. Run the console application.
5. Follow the instructions displayed in the terminal.
